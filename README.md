## 🚀 Featured Projects

### MarketPulse

A backend-focused real-time market data platform designed to demonstrate production-style API architecture, asynchronous processing, caching, persistent market history, and live WebSocket updates.

**Tech:** Node.js, TypeScript, Express, PostgreSQL, Prisma, Redis, WebSockets, BullMQ, Docker, Vitest, GitHub Actions

- REST API with validation, authentication, and rate limiting
- Redis caching and pub/sub
- WebSocket subscriptions for live price updates
- BullMQ background processing
- PostgreSQL market history with indexed queries and pagination
- Dockerized development infrastructure
- Automated CI checks

**Live API:** https://marketpulse-kozq.onrender.com  
**API Docs:** https://marketpulse-kozq.onrender.com/docs/  
**GitHub:** https://github.com/jaiy3/marketpulse
