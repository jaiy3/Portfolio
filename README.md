## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/jaiy3/Portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
